---
name: recap
description: End-of-session capture. Distills the conversation into a structured note and saves it to the best-matching folder in the brain. Use when the user says "recap", "save this session", "write this down", or is wrapping up.
---

Write a short note covering:
- What we figured out or decided
- Anything the user should remember later
- What's still open or needs follow-up

Name the file with today's date and a slug: `YYYY-MM-DD-[topic].md`

Save to the folder that fits best:
- Work on a specific project → projects/[name]/
- General research or learning → refs/
- Nothing specific → daily/ alongside today's note

After saving, scan memory.md. If this session revealed something new about
how the user works or what they care about, append a line under Patterns.
